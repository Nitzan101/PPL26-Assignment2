Q1.3: No, because multi-parameter procedures and multi-expression bodies can be reduced to the L22 format without losing expressive power. A procedure with $n$ parameters is transformed via Currying into $n$ nested single-parameter functions; for example, the L2 call (f x1 x2 x3) is rewritten as (((f x1) x2) x3) in L22.

a body with two expressions e1 e2 is rewritten as ((lambda (unused) e2) e1), which ensures e1 is evaluated before e2. This process is applied recursively for all m expressions until the entire body is reduced to one single-expression application. Since these transformations successfully map any L2 structure directly into the restricted L22 format while preserving the evaluation order, the languages are computationally equivalent.
